# Contributing

- Open an [issue](https://github.com/cuviss-open/soloAS/issues) with the soloAS version, engine version/source, OS, reproduction, expected result and actual result.
- Submit focused pull requests against `main`; maintainers use the same PR process for exported changes.
- Before merging an external PR, maintainers import it into the private development workspace and run the relevant test suite. Results are reported on the public PR before it is merged on GitHub.
- Keep the original contributor as author; do not replace their authorship during import or merge.
- PRs must pass **Documentation links** and **License headers**. Preserve existing notices and licenses; add an appropriate SPDX license header to new source files. See [NOTICE](NOTICE) and [LICENSE](LICENSE).
- Release tags are created only on commits merged into `main`.
- Remove secrets, private project content and personal information from logs and samples.
- Contact: [contact@cuviss.com](mailto:contact@cuviss.com).

- Contributions use the license of their component: Runtime MIT (embedded AngelScript library zlib), GAS Apache-2.0 OR MIT, EnhancedInput MIT, and SoloASBridge MPL-2.0.
